============================
    Introduction to YAML
============================

Ansible Playbooks are text files or configuration files rather that are written in a
particular format called YAML. 

YAML file is there to represent data. In this case configuration data.

Dictionaries - Unordered
List - Ordered

Number of spaces is important in YAML. Here are examples: 
====
Key Value Pair:

Fruit: Apple
Vegetable: Carrot
Liquid: Water
Meat: Chicken

Key there is Fruit, Vegetable, Liquid and Meat
Value there is Apple, Carrot, Water, Chicken
====
Array/lists

Fruits:
-   Orange (<-- element of an array)
-   Apple
-   Banana

Vegetables:
-   Carrot
-   Tomato
-   Cucumber
====
Dictionary/map

Banana:
    Calories: 105
    Fat: 0.4 g
    Carbs: 27 g
====
Dictionary in Dictionary:

Color: blue
Model:
    Name: Corvette
    Year: 1995
Transmission: Manual
Price: $20,000
====
List of Dictionaries

-   Paula's Car
    Model: 
        Name: Alfa Romeo
        Color: Grey
    Price: $8,000
-   Kasia's Car
    Model: 
        Name: Skoda Fabia
        Color: Blue
    Price: $4,500
-   Aga's Car
    Model: 
        Name: Honda
        Color: Silver
    Price: $4,000
====
